# Contributing

Start with [AGENTS.md](AGENTS.md) for the code/test map and
[docs/development.md](docs/development.md) for setup and validation.

Keep fixes focused, add meaningful regression coverage for behavior changes, and
update the documentation that describes that behavior. Use the
[protocol sources](docs/protocol.md) for interoperability changes and distinguish
the local sample from hosted Visa services. Include the checks you actually ran
and any remaining manual validation in the PR description.
